## 4. Hardened Security Defaults (`v1.0.0`)

1. **Fail-Closed Identity & Blank `.env.example`:** `OWNER_TELEGRAM_ID`, `TELEGRAM_BOT_TOKEN`, `CUSTOM_API_KEY`, and `POSTGRES_PASSWORD` ship blank in `.env.example`. Runtime validators reject empty values, `"0"`, negative group IDs, and 10-digit placeholder IDs.
2. **Loopback-Only Host Ports (`0` Public Docker Ports):** Only `127.0.0.1:8200–8202` bind to host loopback; `postgres`, `hermes`, and `vulnclaw` publish zero host ports.
3. **Two-Tier Isolated Docker Networks:** `allinagent_data` (`internal: true`) isolates PostgreSQL 16 from internet egress and peer containers; `allinagent_edge` handles internal service RPCs.
4. **Non-Root Containers & Zero Docker Socket:** Application services execute as unprivileged `10001:10001` with `no-new-privileges:true`, `0700`/`0600` profile isolation, and **never mount `/var/run/docker.sock`**.

## 5. Fresh Installation & Safe Upgrade Commands

### Fresh Installation (`v1.0.0`)

```bash
git clone --branch v1.0.0 https://github.com/Vistapra/ALLINAGENT.git
cd ALLINAGENT
./allinagent setup && ./allinagent up && ./allinagent health
```

### Upgrading from `v1.0.0-rc.1` or Prior Builds

`./allinagent update` checks for active agent/Kanban runs (deferring safely unless `--force` is specified), creates a compressed `pg_dump` snapshot (`data/backups/paperclip-pre-update-*.sql.gz`), pulls verified `v1.0.0` images, restarts services, probes all 6 health endpoints, and automatically rolls back on failure:

```bash
# Linux / macOS
./allinagent update
./allinagent health

# Windows PowerShell
.\allinagent.ps1 update
.\allinagent.ps1 health
```
